# Felipe de León Sáenz Angel — academic website

This folder is a Quarto website project. Edit the `.qmd` files as ordinary Markdown; Quarto generates the finished HTML in `_site/`.

## Preview locally

1. Install Quarto from <https://quarto.org/docs/get-started/> if it is not already installed.
2. Open a terminal in this folder.
3. Run `quarto preview`.

Quarto will build the site, start a local preview, and refresh it when a source file changes. To generate the site without starting the preview server, run `quarto render`.

The generated `_site/` directory is disposable build output. The source files in this folder are the version to keep and edit.
